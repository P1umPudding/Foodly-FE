# Spec (Dispatcher)

## Context
Portionsfeld zeigt leer/0/negativ, obwohl die Mengen unverändert bleiben — siehe Originalmeldung oben.

## Goal
Das Portionsfeld zeigt nach dem Verlassen immer den tatsächlich angewendeten Wert.

## Behaviour
Leer oder 0 → Feld springt auf die Standardportionen (Faktor 1), auch wenn der Faktor schon 1 war. Negativ → Feld springt auf den aktuellen Wert zurück. Gültige Werte wie bisher.

## Acceptance criteria
1. Rezept mit 4 Portionen, unskaliert: Feld leeren + blur → Feld zeigt 4.
2. „0“ + blur → 4.
3. „-2“ + blur → aktueller Wert (z. B. 4 bzw. 6 bei Skalierung).
4. Gleiches Verhalten im Multiplikator-Modus (ohne Portionsangabe): leer/0 → ×1, negativ → aktueller Wert.
5. Tests für alle Fälle.

## Non-goals
Keine Änderung der Stepper-Logik.
