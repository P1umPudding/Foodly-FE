# Plan — #345 Web-App installierbar (PWA mit minimalem Service Worker)

Base: main @ 6944ac0, branch `agent/issue-345`. Spec: `docs/superpowers/specs/2026-11-26-issue-345-design.md` (issue #345 + worker assumptions A1–A8).

## Step 1 — Service worker `public/sw.js`
- Plain JS, no imports: `install` → `self.skipWaiting()`; `activate` → `event.waitUntil(self.clients.claim())`; a `fetch` listener that returns without `respondWith`.
- 2–3 line header (why): Chrome ≥ 108/112 installs on the manifest alone; the worker with a fetch listener is for older Chromium, Samsung Internet and Brave. No cache (offline is Phase 8); Chrome may warn about a no-op fetch handler — intended. To remove it later, ship a self-unregistering `sw.js`, never delete the file.

## Step 2 — Registration `src/serviceWorker.ts`
- `export function registerServiceWorker(): void`
  - First line, reading env directly so Vite folds it to dead code in dev/native: `if (!import.meta.env.PROD || import.meta.env.MODE === 'native') return`.
  - Then `if (isNative() || !('serviceWorker' in navigator)) return`.
  - `register = () => navigator.serviceWorker.register(`${import.meta.env.BASE_URL}sw.js`).catch((error: unknown) => console.error(error))` (default scope = BASE_URL).
  - Run now if `document.readyState === 'complete'`, else `window.addEventListener('load', register, { once: true })`.
- `src/main.tsx`: `registerServiceWorker()` right after `startSplash()` (outside React → no StrictMode double call).
